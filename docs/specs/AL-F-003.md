## Goal
One `chat()` function talks to the local model through LiteLLM, and a scripted fake with the same signature lets
every later lesson and test run with no model and no network. A test-wide guard proves that nothing calls out.

## Acceptance criteria
1. **No-network setup (REQ-005).** At the top of `model.py`, before `import litellm`:
   - set `os.environ["LITELLM_LOCAL_MODEL_COST_MAP"] = "True"`;
   - append `127.0.0.1` and then `localhost` to `NO_PROXY` and to `no_proxy`. Keep the existing entries, join with
     commas and add no duplicates. For example, `example.internal` becomes `example.internal,127.0.0.1,localhost`.

   `fakes.py` and `tests/conftest.py` must not import `litellm`.
2. **Types.** In `model.py`, frozen dataclasses:
   - `ToolCall(id: str, name: str, arguments: str)`;
   - `Reply(text: str, tool_calls: list[ToolCall], usage: dict)`. `usage` always has `prompt_tokens`,
     `completion_tokens` and `total_tokens`; a value that is missing or `None` gives 0.

   Errors: `class ModelError(RuntimeError)`, with `ModelServerDown(ModelError)` and `ModelTimeout(ModelError)`.
3. **chat** (REQ-004): `chat(messages, tools=None, response_format=None, thinking=False, *, settings=None) ->
   Reply`. When `settings` is `None`, use `settings.load()`.
   - First call `model_server.check_host(settings)` (local only, REQ-053; its error propagates).
   - Call `litellm.completion(model=f"openai/{model_name}", api_base=base, api_key="local",
     timeout=timeout_s, messages=prepared)`. Add `tools=` and `response_format=` only when they are given. Do not
     set `num_retries`.
   - Build `base` with `urllib.parse.urlunsplit(("http", f"{host}:{port}", "/v1", "", ""))`.
   - `prepared` is a deep copy; the caller's list and dicts are never changed.
   - When `thinking` is false:
     - if the first message has role `system` and its `content` is a `str`, append `" /no_think"`, unless the
       content already `endswith("/no_think")`;
     - if the first message is not a system message, insert `{"role": "system", "content": "/no_think"}` first;
     - a system content that is not a `str` raises `ModelError("system message content must be text")`.
   - When `thinking` is true, send the messages unchanged.
   - Read the response with attribute access:
     - `choices[0].message.content or ""`;
     - `message.tool_calls or []`, mapping each to `ToolCall(tc.id, tc.function.name, tc.function.arguments)`;
     - `response.usage` (may be `None`).
   - An empty `choices` raises `ModelError("model returned no choices")`.
   - Errors, checked in this order and chained with `from`. For example, with host `127.0.0.1`, port `8090` and
     `timeout_s` 120:
     - `litellm.Timeout` gives `ModelTimeout("model did not answer within 120 s (timeout_s)")`;
     - `litellm.APIConnectionError` gives `ModelServerDown("cannot reach the model at 127.0.0.1:8090; run:
       agent-lab model start")`;
     - `litellm.BadRequestError` gives `ModelError(str(error))`. The text keeps LiteLLM's prefix and contains the
       server's message.
4. **Fake script** (shared definitions). `fakes.load_script(source)` takes a `list`, a `Path` or a `str` (a `str`
   is always a path, never JSON) and returns a new list. It raises `ValueError` when any of these is true:
   - the top level is not a list;
   - a reply has both keys, neither key, or extra keys;
   - `text` is not a `str`;
   - `tool_calls` is empty or not a list;
   - a call has keys other than `name` and `arguments`, or either is not a `str`;
   - `arguments` is not valid JSON.

   Each message names the reply index. A missing file or invalid JSON raises `ValueError` naming the path.
   `fakes.builtin(name) -> Path` returns `Path(__file__).parent / "fake_scripts" / f"{name}.json"`.
5. **FakeModel(script)**:
   - `__init__` calls `load_script`.
   - `chat(messages, tools=None, response_format=None, thinking=False, *, settings=None) -> Reply` accepts
     `settings` and ignores it. It returns the next reply.
   - Tool call ids are `call_1`, `call_2`, ..., counted across every call in the run, including two calls in one
     reply.
   - `usage` has all three keys set to 0.
   - Before it replies, it appends `{"messages": deepcopy(messages), "tools": tools, "response_format":
     response_format, "thinking": thinking}` to `self.requests`. `tools` and `response_format` are stored as given.
   - When the script is used up, it raises `class ScriptExhausted(RuntimeError)`.
6. **FakeChatModel(script)**: a pydantic `BaseChatModel` subclass (`langchain_core` only).
   - Declare the fields `script: list`, `requests: list = Field(default_factory=list)` and
     `bound_tools: list = Field(default_factory=list)`, plus private `_index` and `_calls` (`PrivateAttr(0)`).
   - `__init__(self, script, **kwargs)` calls `super().__init__(script=load_script(script), **kwargs)`.
   - `_generate(self, messages, stop=None, run_manager=None, **kwargs)`:
     - appends `deepcopy(list(messages))` to `requests`;
     - returns `ChatResult(generations=[ChatGeneration(message=AIMessage(content=text, tool_calls=[{"name",
       "args": json.loads(arguments), "id": "call_N", "type": "tool_call"}]))])`;
     - numbers the ids as in AC5;
     - raises `ScriptExhausted` when the script is used up.
   - `bind_tools(tools, **kwargs)` stores `list(tools)` in `bound_tools` and returns `self`.
   - The `_llm_type` property returns `"agent-lab-fake"`.
7. **two_tool.json**, in this order:
   1. a tool call `multiply` with `{"a": 17, "b": 23}`;
   2. a tool call `write_note` with `{"name": "result", "text": "17 x 23 = 391"}`;
   3. the text `The answer is 391. I saved it as the note "result".`

   `arguments` are JSON strings.
8. **Network guard (REQ-005 AC1)** in `tests/conftest.py`. It installs at module level, which covers imports
   during collection; this meets "autouse". Live tests stay guarded too, because they use loopback only.
   - Wrap `socket.socket.connect` and `socket.socket.connect_ex`. For an `AF_INET`/`AF_INET6` address tuple, compare
     `str(address[0])`: only `127.0.0.1`, `::1` and `localhost` (any case) are allowed. Anything else raises
     `RuntimeError("network blocked by test guard: <host>")` BEFORE the real call. Addresses that are not tuples
     pass through.
   - Wrap `socket.getaddrinfo` the same way on its `host` argument (`None`, `""`, the loopback names and numeric
     loopback are allowed), so DNS lookups cannot leak. UDP `sendto` is not guarded (accepted; nothing here uses
     UDP).
   - Expose `REAL_CONNECT`, `REAL_CONNECT_EX` and `REAL_GETADDRINFO` as module constants.
   - Do not wrap twice: mark wrappers with `_agent_lab_guard = True` and skip when it is already present.
   - `conftest.py` defines no fixtures that change `subprocess` or settings.
9. **Plain English (REQ-052).** The modules and every class, function and method in `model.py` and `fakes.py`
   (including private ones and `_llm_type`) have a docstring in short eli5, ASD-STE100 sentences. A sentence is
   the text split on `[.!?]` followed by whitespace or the end; it has at most 20 `split()` words. Neither file
   contains `http://` or `https://` anywhere, comments included.
10. **Tests.** Test files may contain URL literals. No test reaches the network or a model.
    - `tests/test_model.py`. It patches `litellm.completion` and builds responses with `types.SimpleNamespace`.
      `S = Settings(host="127.0.0.1", port=9999, model_name="m", timeout_s=7)`. Cover:
      - the kwargs: `model == "openai/m"`, `api_base == "http://127.0.0.1:9999/v1"`, `api_key == "local"`,
        `timeout == 7`, and no `num_retries`;
      - `tools` and `response_format` are passed only when given;
      - the `/no_think` rules: appended, inserted, not doubled, unchanged with `thinking=True`, and a non-str
        system content raises;
      - the caller's messages are unchanged;
      - mapping text, two tool calls with `arguments` kept as strings, `tool_calls=None`, and usage `None`;
      - empty `choices` raises;
      - the errors, with exact message equality for timeout and down. Build them as
        `litellm.Timeout("t", model="m", llm_provider="openai")`,
        `litellm.APIConnectionError("c", llm_provider="openai", model="m")` and
        `litellm.BadRequestError("too long", model="m", llm_provider="openai")`; the third gives a `ModelError`
        whose text contains `too long`;
      - a non-local host raises `model_server.ModelServerError`, and `completion` is not called;
      - `chat(msgs)` with no `settings` uses a patched `settings.load`;
      - `not hasattr(litellm, "telemetry")` (MEASURED fact; a version bump must re-check REQ-005).
    - `tests/test_fakes.py`:
      - `FakeModel(builtin("two_tool"))` replays: ids `call_1`, `call_2`, then text containing `391`;
      - it records 3 requests with deep-copied messages, then raises `ScriptExhausted`;
      - a reply with two calls gives `call_1` and `call_2`, and the next reply continues at `call_3`;
      - `load_script`:
        - accepts a list, a `Path` and a `str`, and does not change the caller's list;
        - rejects both keys, non-JSON `arguments` and a non-list top level, naming the index or the path;
      - `FakeChatModel(script)` with a positional argument: `bind_tools` returns the same object, then `invoke`
        returns `AIMessage`s with parsed `args` and ids, and then text; it records requests and raises
        `ScriptExhausted`;
      - the AC9 `ast` check on `model.py` and `fakes.py`: the module docstring and every `FunctionDef`,
        `AsyncFunctionDef` and `ClassDef`; the whole file text is checked for URLs.
    - `tests/test_network_guard.py`:
      - connects to `("93.184.216.34", 80)` and `("2001:db8::1", 80, 0, 0)` raise via `connect` and
        `connect_ex`, and the `REAL_*` constants (patched with a recording stub) are not called;
      - a client socket connects to a `127.0.0.1:0` listener, and `::1` is allowed;
      - `getaddrinfo("example.com", 80)` raises, and `getaddrinfo("localhost", 80)` works;
      - the env check runs in a subprocess, `[sys.executable, "-I", "-c", ...]` with `PYTHONPATH=src`:
        - with `NO_PROXY=example.internal` and no `LITELLM_LOCAL_MODEL_COST_MAP`, importing `agent_lab.model` gives
          `LITELLM_LOCAL_MODEL_COST_MAP == "True"` and `NO_PROXY == "example.internal,127.0.0.1,localhost"`;
        - with `NO_PROXY=127.0.0.1`, it gives `127.0.0.1,localhost`;
      - REQ-050 AC1: `tomllib` reads `pyproject.toml` (`Path(__file__).resolve().parents[1]`); `addopts` contains
        `-m 'not live'` and the `live` marker is registered.
11. **Full suite.** `.venv\Scripts\python.exe -m pytest -rs` passes with the new conftest, with 0 skipped. The
    existing `test_settings`, `test_project` and `test_model_server` tests still pass.
