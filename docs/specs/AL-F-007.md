## Goal
The agent can look things up in a small local library of plain-English docs about the ideas Agent Lab teaches.
Search is simple and predictable, so a learner can see exactly why a result came back.

## Acceptance criteria
1. **Folder.** `_docs_dir() -> Path` returns `Path(settings.load().docs_dir)`, read at each call, like
   `_notes_dir`. A `SettingsError` becomes `ToolError(str(error))`. Every new function has a docstring whose
   sentences have at most 20 words (REQ-052 AC1).
2. **Tool** `search_docs(query: str, limit: int = 3) -> list[dict]` (`@mcp.tool`). Docstring: "Search the local
   docs for words. Give query words and limit from 1 to 10." Steps, in this order:
   1. `words = set(re.findall(r"[a-z0-9]+", query.lower(), re.ASCII))`. No words raises
      `ToolError("query needs at least one word")`.
   2. A `limit` outside 1..10 raises `ToolError("limit must be from 1 to 10, got <limit>")`. Type errors (for
      example a string) come from FastMCP and are not asserted.
   3. `base = _docs_dir().resolve()`. If `base` is not a folder (missing, or a file), return `[]`.
   4. Take each `*.md` directly in `base` (not recursive). Skip any entry that is not `is_file()` or whose
      `resolve()` is outside `base`. Skip a file that raises `OSError` on read. Read as UTF-8 with
      `errors="replace"`.
   5. Lines come from `text.split("\n")`, each with one trailing `\r` removed. Line numbers start at 1.
   6. The hits on a line are the number of tokens from `re.findall(r"[a-z0-9]+", line.lower(), re.ASCII)` that are
      in `words`. A word repeated in the query counts once, but every occurrence in the line counts. Matching is
      whole-word and case-insensitive.
   7. The file score is the total hits. The best line is the first line with the most hits.
   8. Return items `{"file": <Path.name>, "line": <int>, "text": <best line stripped, first 300 characters>}` for
      files with a score above 0. Order with `sorted(key=lambda item: (-score, name))` (Python's case-sensitive
      string order), then take the first `limit`.
3. **Corpus** (`docs_corpus/*.md`, UTF-8, LF, no carriage returns). Three plain docs, each 15 to 30 lines, with
   line 1 starting `# `, every sentence at most 20 words, and no URLs. The eli5 and ASD-STE100 tone is checked in
   review. Required content, which must be accurate:
   - `mcp-basics.md`, "MCP basics":
     - MCP (Model Context Protocol) lets a program offer tools, resources and prompts to an AI client;
     - a server lists tools with names, descriptions and input schemas;
     - the client calls a tool by name with JSON arguments;
     - the stdio transport means the client starts the server and talks through standard input and output;
     - a tool error comes back as a result marked as an error (`isError`), so the model can read it and retry.
   - `tool-calling.md`, "Tool calling":
     - the request sends tool schemas with the messages;
     - the model may answer with `tool_calls` (an id, a name and JSON arguments) instead of text;
     - the program runs the tool and sends a message with `role` set to `tool` and the same `tool_call_id`;
     - then the model answers with text;
     - a small model can pick wrong arguments, so clear errors help.
   - `agent-loop.md`, "The agent loop":
     - one step is one model call;
     - the loop calls the model, runs any tool calls, adds the results, and calls again;
     - it stops on a text answer or at the step limit `max_steps` (default 6 in settings);
     - a trace records each step.

   Distinctive words (tested): `stdio` appears only in `mcp-basics.md`, `role` only in `tool-calling.md`, and
   `trace` only in `agent-loop.md`. Whole-word, case-insensitive.
4. **Local only (REQ-053).** No `http://` or `https://` in the module. This is stricter than REQ-053 on purpose.
   No network code. F-005 and F-006 do not change.
5. **Tests** (`tests/test_tools_docs.py`; `ROOT = Path(__file__).resolve().parents[1]`; in-memory `Client` in
   `asyncio.run`). Every test runs `monkeypatch.chdir(tmp_path)` and sets `AGENT_LAB_DOCS_DIR`. Results are
   compared with `result.data`, a list of dicts: a non-empty result equals the exact expected list, an empty one is
   `[]`, and `line` is an `int`. Cover:
   - **Ranking.** Fixtures:
     - `alpha.md`: `the junction here` on line 1;
     - `beta.md`: line 3 = `junction and junction`;
     - `gamma.md`: no match.

     Query `junction` equals `[{"file": "beta.md", "line": 3, "text": "junction and junction"}, {"file":
     "alpha.md", "line": 1, "text": "the junction here"}]`.
   - **Tie.** `b.md` and `a.md` each have one `tie`: the order is `a.md`, then `b.md`.
   - **Case and whole words.** `Junction` and `JUNCTION` match. A file with only `junctions junctionx` gives `[]`
     for `junction`.
   - **Line endings.** A CRLF file gives the right line number and text without a carriage return.
   - **Ignored entries.** `sub/x.md` containing `junction` and a folder `d.md/` are not in any result.
   - **Errors and limits.**
     - An absent word gives `[]`.
     - A missing folder, and `AGENT_LAB_DOCS_DIR` pointing at a file, both give `[]`.
     - `""`, `"   "`, `"!!!"`, and `""` with `limit=0` give `at least one word` (the query is checked first).
     - `limit` 0 and 11 give `1 to 10`. `limit=1` returns one item.
     - A best line of 400 characters returns 300.
   - **Shipped corpus** (`AGENT_LAB_DOCS_DIR = ROOT / "docs_corpus"`). The first result is `mcp-basics.md` for
     `stdio`, `tool-calling.md` for `role` and `agent-loop.md` for `trace`.
   - **Corpus structure.** Each file:
     - has 15 to 30 lines;
     - has line 1 starting with `# `;
     - contains no carriage return and no `http`;
     - has no sentence over 20 words;
     - contains its required words:
       - `mcp-basics`: `stdio`, `schemas`, `isError`;
       - `tool-calling`: `tool_calls`, `tool_call_id`, `role`;
       - `agent-loop`: `max_steps`, `trace`.

     Each distinctive word appears in its own file only.
   - **Tool names** include `search_docs`.
   - **No URLs** in `ROOT / "src/agent_lab/mcp_server.py"`.

   A link that escapes the folder is not tested on purpose: a file symlink needs privilege on Windows, and a
   junction is a folder (skipped by `is_file`).
6. **Full suite.** `.venv\Scripts\python.exe -m pytest -rs` passes, with 0 skipped and at least 82 + the new
   tests.
