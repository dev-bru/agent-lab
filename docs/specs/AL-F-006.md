## Goal
The agent can save, read and list short notes, but only inside one folder. No name, link or junction can make it
read or write anywhere else.

## Files in scope (only these may change)
- src/agent_lab/mcp_server.py
- tests/test_tools_notes.py (new)

## Acceptance criteria
1. **Folder.** `_notes_dir() -> Path` returns `Path(settings.load().notes_dir)`, using `from agent_lab import
   settings`.
   - Settings are read at each call, so `AGENT_LAB_NOTES_DIR` works. The MCP client passes folder settings through
     the environment.
   - A relative path is relative to the current folder.
   - A `SettingsError` becomes `ToolError(str(error))`.
   - If `notes_dir` is itself a junction or link, `resolve()` follows it, and the target becomes the base. This is
     intended.
2. **Name check** (`_note_path(name) -> Path`), before any file access:
   - the name must pass `re.fullmatch(r"[A-Za-z0-9_-]{1,64}", name, re.ASCII)`;
   - the name, upper-cased, must not be `CON`, `PRN`, `AUX`, `NUL`, `COM1`..`COM9` or `LPT1`..`LPT9`.

   Otherwise raise `ToolError("note names use 1 to 64 letters, digits, _ or -, and not a device name such as CON;
   got '<name>'")`.

   Then set `base = _notes_dir().resolve()` and `path = base / f"{name}.md"`. If `path.resolve()` is not
   `is_relative_to(base)`, raise `ToolError("note path is outside the notes folder")`.
3. **Tools.** Each uses `@mcp.tool`. The docstring tells a small model the argument rules; each sentence has at
   most 20 words.
   - `write_note(name: str, text: str) -> str`. Docstring: "Save a note. Give name (letters, digits, _ or -, up
     to 64) and text (up to 10000 characters)." Order:
     1. check the name;
     2. check the length in Unicode code points: more than 10000 raises
        `ToolError("note text is longer than 10000 characters (<n>)")`;
     3. `text.encode("utf-8")` (a `UnicodeEncodeError` becomes `ToolError("cannot write note '<name>': text is
        not valid UTF-8")`);
     4. if the file exists and `os.stat(path).st_nlink > 1`, raise `ToolError("cannot write note '<name>': it is
        linked to another file")` (hard-link escape);
     5. create the folder (`parents=True, exist_ok=True`);
     6. write with `open(path, "w", encoding="utf-8", newline="")`;
     7. return `saved note '<name>'`, or `updated note '<name>'` when the file existed before.

     Any other `OSError` becomes `ToolError("cannot write note '<name>': <error.strerror or class name>")`, with
     no paths in the message.
   - `read_note(name: str) -> str`. Docstring: "Read a saved note by name. Use list_notes to see the names."
     - It checks the name and reads with `open(path, encoding="utf-8", newline="")`, so text round-trips exactly.
     - A missing file raises `ToolError("no note named '<name>'; use list_notes to see the names")`.
     - Other `OSError`/`UnicodeError` (for example a folder named `<name>.md`) raise `ToolError("cannot read note
       '<name>': <reason>")`, with no paths.
   - `list_notes() -> list[str]`. Docstring: "List the names of saved notes."
     - A missing folder gives `[]` and is not created.
     - Otherwise it returns `sorted()` (case-sensitive) stems of the `*.md` entries that meet all of these: they
       are files, they resolve inside the base, and the stem passes the name rule.
4. **Local only (REQ-053).** No URL text and no network code. The F-005 tools and module start-up do not change.
5. **Tests** (`tests/test_tools_notes.py`, pytest). Use the in-memory `Client(mcp_server.mcp)` in `asyncio.run`,
   as in `tests/test_tools_math_time.py`. Error checks use `raise_on_error=False`, `is_error` and `content[0].text`.
   Every test runs `monkeypatch.chdir(tmp_path)` (so the PC's own `agent-lab.toml` is not read) and
   `monkeypatch.setenv("AGENT_LAB_NOTES_DIR", str(tmp_path / "notes"))`, with a non-empty value. No test skips.
   Cover:
   - **Round trip.** Write then read returns `Grüße, नमस्ते ✓` and `"a\r\nb\n"` exactly. `list_notes`
     includes the name. A second write returns `updated note '...'`.
   - **Relative folder.** With `AGENT_LAB_NOTES_DIR=notes_rel`, writing `n` creates `tmp_path/"notes_rel"/"n.md"`.
   - **Bad names.** Test `"../x"`, `"a/b"`, `"C:x"`, `"con"`, `"Com1"`, `"LPT9"`, `"NUL"`, `"aux"`, `"COM9"`, `""`
     and `"a" * 65`.
     - Each gives an error containing `note names use`, for `write_note` and `read_note`.
     - Run this twice: with the notes folder missing, and with it present and holding one note.
     - Each time, a recursive listing of `tmp_path` with file sizes is the same before and after.
   - **Length.** 10000 characters are accepted. 10001 give an error containing `10000`.
   - **Junction escape.**
     - Setup: create the notes folder and `tmp_path/"outside"` (with `keep.txt` = `secret`), then run
       `subprocess.run(["cmd", "/c", "mklink", "/J", str(notes / "x.md"), str(outside)], check=True,
       capture_output=True)` (no admin needed).
     - `write_note("x", "hi")` and `read_note("x")` give `note path is outside the notes folder`.
     - `outside` still holds only `keep.txt` with `secret`.
     - `list_notes()` does not include `x`.
     - Remove the junction with `os.rmdir(notes / "x.md")` in a `finally`.
     - This test MEASURES that `resolve()` follows junctions.
   - **Hard link.** Create `outside/target.md` and `os.link(outside / "target.md", notes / "h.md")`.
     `write_note("h", "x")` gives an error containing `linked`, and the outside file is unchanged.
   - **Folder named `d.md`.** It is not listed, and `read_note("d")` gives a `cannot read note` error.
   - **Missing.** A missing note gives an error naming `list_notes`. `list_notes()` with no folder gives `[]`,
     and the folder is not created.
   - **Tool names.** They include `write_note`, `read_note` and `list_notes` (subset check).
   - **No URLs.** The module source contains no `http://` or `https://`.
6. **Full suite.** `.venv\Scripts\python.exe -m pytest -rs` passes, with 0 skipped and at least 72 + the new
   tests. The F-005 tests and the docstring test still pass.

## Decision Log
- The real path is checked before every file access, so a junction cannot redirect a write (by: AI, 2026-10-30).
- The folder is created only after the name and length checks, so a rejected call leaves no trace (by: AI,
  2026-10-30).

- Names cannot hold separators, so the only link that can matter is the entry `<name>.md` itself; the `.md`
  suffix does not make device names safe on Windows, so bare device names are refused (by: AI, 2026-10-30).
- Hard links are refused by `st_nlink > 1` before a write (by: AI, 2026-10-30).
- Known limit: check-then-open is racy if an outside process swaps the file for a link; the tools cannot create
  links, so this is accepted (by: AI, 2026-10-30).
