## Acceptance criteria
1. **Package:** `src/agent_lab/__init__.py` has a module docstring and `__version__ = "0.1.0"`.
2. **Settings** (`src/agent_lab/settings.py`):
   - A frozen dataclass `Settings` with these fields and defaults: `llama_server: str = "llama-server.exe"`,
     `model: str = "models/Qwen3-1.7B-Q8_0.gguf"`, `host: str = "127.0.0.1"`, `port: int = 8090`,
     `model_name: str = "qwen3-1.7b"`, `max_steps: int = 6`, `timeout_s: int = 120`,
     `notes_dir: str = "sandbox/notes"`, `docs_dir: str = "docs_corpus"`, `runs_dir: str = "runs"`.
   - `load(path: Path | None = None, env: Mapping[str, str] | None = None) -> Settings`. Load order: defaults,
     then the TOML file (read with `tomllib`), then `AGENT_LAB_<FIELD>` environment variables (upper case).
     `path` defaults to `agent-lab.toml` in the current folder and may be missing. `env` defaults to
     `os.environ`.
   - `class SettingsError(ValueError)` is defined in `settings.py`. Values are converted to each field's type
     (`int` fields with `int()`, `str` fields as given; there are no bool or float fields). An empty environment
     string counts as unset. A TOML syntax error is raised as `SettingsError` naming the file. A bad value (for example `AGENT_LAB_PORT=abc`, or `port = "x"` in
     the file) raises `SettingsError`, with a message that names the key, for example
     `port must be an integer, got 'abc'`.
   - Unknown keys in the file raise `SettingsError` naming the key.
3. **Example file:** `agent-lab.example.toml` lists every field with exactly the default values from AC2 and a
   one-line comment each. The two path fields (`llama_server`, `model`) keep their relative defaults, with a comment
   telling the user to set real paths in their own `agent-lab.toml`. The file contains no drive letters or user
   folders.
4. **CLI** (`src/agent_lab/cli.py`): `main(argv=None) -> int` uses argparse with the program name `agent-lab`
   and the subcommands `chat` and `model`.
   - `--help` lists both subcommands with one-line help.
   - Each subcommand prints `Not built yet: <name> comes in a later feature.` and returns 2.
   - `if __name__ == "__main__": raise SystemExit(main())`.
5. **.gitignore:** `.venv/`, `__pycache__/`, `.pytest_cache/`, `agent-lab.toml` (the user's real settings),
   `sandbox/`, `runs/`, `.agent-lab/`.
6. **README.md** (short; the full README is F-017): what Agent Lab is in 2 sentences, a numbered setup list of at
   most 6 steps (install uv, `uv sync`, copy `agent-lab.example.toml` to `agent-lab.toml` and set `llama_server` and `model` to the real paths,
   `uv run agent-lab --help`), and the test command.
7. **Plain English:** every module and public function has a docstring in short sentences, eli5 level, ASD-STE100
   style, with at most 20 words per sentence.
8. **pytest config:** `[tool.pytest.ini_options]` adds `pythonpath = ["src"]`, keeping `addopts`, `markers` and
   `testpaths`.
9. **Tests:**
   - `tests/test_settings.py`:
     - the defaults with no file and an empty env;
     - the example file loads and gives the same values as the defaults;
     - the file overrides defaults;
     - an env override (`AGENT_LAB_PORT=9999` gives 9999), which wins over the file;
     - a bad env value and a bad file value raise `SettingsError` naming the key;
     - an unknown file key raises;
     - a `Settings` object cannot be changed (assigning a field raises `dataclasses.FrozenInstanceError`).
   - `tests/test_project.py`:
     - (REQ-001 AC2) every `[project].dependencies` entry in `pyproject.toml` uses `==`, and `tzdata` is
       present;
     - (REQ-001 AC3) `subprocess.run([sys.executable, "-m", "agent_lab.cli", "--help"], cwd=root,
       env={**os.environ, "PYTHONPATH": str(root / "src")}, capture_output=True, text=True, timeout=60)`, where
       `root = Path(__file__).resolve().parents[1]` (pytest's `pythonpath` does not reach child processes), exits 0
       and its output contains `chat` and `model`;
     - (REQ-002 AC3) no `*.py`, `*.md` or `*.toml` file under `src/`, `lessons/` (if it exists) or `tests/`
       (skipping `__pycache__`) matches the drive-path regex `(?<![A-Za-z0-9/])[A-Za-z]:[\\/](?!/)` (a letter,
       a colon and a slash, not part of a URL such as `http://`) or the user-folder regex `(?i)[\\/]users[\\/]`;
     - (REQ-054 AC1) every dependency name in `pyproject.toml` (project and the `dev` group; parse the name before
       `==` and compare lower-case with `_` treated as `-`) appears in `docs/DEPENDENCIES.md` (same normalising).
       The file also contains the text `llama.cpp` and a 64-hex SHA-256 (regex `\b[0-9a-f]{64}\b`). The
       orchestrator checked these rows exist (2026-10-31).

     The drive-path test must not trip on its own regex: build the pattern from parts, or skip that file.
