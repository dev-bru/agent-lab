## Goal
Prove the server speaks MCP correctly, and show a learner what an MCP client does. The lesson starts the real
server as a child process, asks what it offers, and calls a tool. It needs no model.

## Facts
- MEASURED 2026-10-30 (venv import, fastmcp 4.1.4):
  - `fastmcp.client.transports.StdioTransport(command, args, env=None, cwd=None, keep_alive=None, log_file=None)`;
  - `fastmcp.Client` has `initialize_result`, `list_tools`, `call_tool`, `list_resources` and `read_resource`.
- DOCUMENTED (fastmcp 4.1.4 source, read 2026-10-30 by the spec auditor):
  - `keep_alive` defaults to True, so the child may outlive the `async with` block;
  - with `env=None` the child gets a reduced environment, so pass the full environment;
  - `Resource.uri` is a pydantic `AnyUrl` (compare with `str(...)`);
  - `read_resource(uri)` returns a list of contents with `.text`;
  - importing `agent_lab.mcp_server` switches the FastMCP update check off before FastMCP loads.

## Acceptance criteria
1. **Protocol test** (`tests/test_mcp_protocol.py`, REQ-024). Use the in-memory `Client(mcp_server.mcp)` inside
   ONE `async with` per test, run with `asyncio.run`, like the `call` helper in `tests/test_tools_math_time.py`.
   Set up with `monkeypatch.chdir(tmp_path)`, `monkeypatch.setenv("AGENT_LAB_NOTES_DIR", str(tmp_path / "notes"))`
   and `monkeypatch.setenv("AGENT_LAB_DOCS_DIR", str(ROOT / "docs_corpus"))`, where
   `ROOT = Path(__file__).resolve().parents[1]`.
   - The tool names equal exactly `{add, multiply, convert_units, write_note, read_note, list_notes, now,
     days_between, search_docs}`.
   - Every tool has `tool.description.strip()` non-empty and `tool.inputSchema["type"] == "object"`.
   - Every tool is called once (default `raise_on_error=True`, so any error fails the test). Values are read from
     `.data`:
     - `add(2, 3) == 5`, `multiply(17, 23) == 391`, `convert_units(1, "mi", "km") == 1.609344`;
     - `write_note("t", "hi")`, then `read_note("t") == "hi"`, and `"t" in list_notes()`;
     - `now("UTC")` is a str ending `+00:00`, and `days_between("2026-10-29", "2026-12-31") == 63`;
     - `search_docs("stdio")[0]["file"] == "mcp-basics.md"`.
2. **Lesson** `lessons/05_mcp_client.py`, runnable alone with no model. It imports only `argparse`, `asyncio`,
   `os`, `sys` and `fastmcp`. It needs no `agent_lab` import; the child server needs `agent_lab` installed or on
   `PYTHONPATH`, which `uv run` provides. It has a module docstring of 2 to 4 short sentences, a docstring on
   every function, and a plain comment before each step. Every docstring sentence has at most 20 words (the
   docstring test). At the start of `main`, call `sys.stdout.reconfigure(encoding="utf-8")`.
   - Arguments: argparse with only `--server MODULE` (default `agent_lab.mcp_server`).
   - Steps inside `async def run(module) -> int`, called with `asyncio.run`, printing with `flush=True`:
     1. Start the server as a child: `StdioTransport(command=sys.executable, args=["-m", module],
        env={**os.environ}, cwd=os.getcwd(), keep_alive=False)`, then `async with Client(transport) as client:`.
     2. Print `server: <name> <version>` from `client.initialize_result.serverInfo`.
     3. Print `tools: <count>`, then one line per tool sorted by name:
        `- <name>: <description.splitlines()[0]>`.
     4. Call `multiply` with `{"a": 17, "b": 23}` and print `[tool: multiply] 17 x 23 = <result.data:g>`, which
        shows `391`.
     5. `resources = await client.list_resources()`:
        - if it is empty, print `no resources offered`;
        - if no item has `str(r.uri) == "docs://mcp-basics"`, print `resource docs://mcp-basics not offered`;
        - otherwise read it, then print `resource docs://mcp-basics:` and `contents[0].text`.
   - Errors: any `Exception` (including an exception group) while talking to the server prints
     `error: <type name>: <message>` to stderr, with the message `server did not start` when `str(error)` is
     empty. It returns 1. Success returns 0. No traceback.
   - `if __name__ == "__main__": raise SystemExit(main())`.
3. **Test helper server** `tests/mcp_with_resource.py`. It has a module docstring and:
   - `from agent_lab.mcp_server import mcp`;
   - `ROOT = Path(__file__).resolve().parents[1]`;
   - `@mcp.resource("docs://mcp-basics")`, returning `(ROOT / "docs_corpus" / "mcp-basics.md").read_text(
     encoding="utf-8")`, read at call time;
   - `if __name__ == "__main__": mcp.run(show_banner=False)`.

   It is a test helper only. The real server stays without resources until F-018.
4. **Lesson tests** (`tests/test_lesson_05.py`). Each run is `subprocess.run([sys.executable,
   "lessons/05_mcp_client.py", ...], cwd=ROOT, env={**os.environ, "PYTHONPATH": os.pathsep.join([str(ROOT /
   "src"), str(ROOT)]), "AGENT_LAB_NOTES_DIR": str(tmp_path / "notes")}, capture_output=True, encoding="utf-8",
   errors="replace", timeout=120)`. Cover:
   - **Default server** (REQ-014 AC1; phase-2 "done when"):
     - exit 0;
     - stdout contains `server: agent-lab`, `tools: 9`, a `- <name>:` line for each of the 9 tools,
       `[tool: multiply] 17 x 23 = 391` and `no resources offered`;
     - output has no `Traceback`, and stderr has no `http://` or `https://`.
   - **With a resource** (REQ-014 AC2): `--server tests.mcp_with_resource` exits 0. Stdout contains
     `resource docs://mcp-basics:` and `# MCP basics`.
   - **Bad module**: `--server agent_lab.no_such_module` with `timeout=60` exits 1. Stderr contains a line starting
     `error: ` with more text after the type name, and no `Traceback`. The child prints `No module named ...`,
     which is fine.
   - **No URLs** in the lesson source or the helper.

   The conftest network guard does not run in the child. The no-network evidence here is the source scan, the
   stderr check, and F-005's start-up settings.
5. **Full suite.** `.venv\Scripts\python.exe -m pytest -rs` passes, with 0 skipped and at least the baseline (93)
   plus the new tests. The docstring test covers the lesson.
