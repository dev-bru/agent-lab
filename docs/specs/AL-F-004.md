## Goal

sent, the reply, and the token counts. With `--fake` it runs with no model. The repo-wide docstring rule (REQ-052)
gets its real test.

## Round 2 change (orchestrator live check, 2026-10-30)
MEASURED: with the server stopped, `lessons/01_model_call.py` printed a LiteLLM banner and a traceback. LiteLLM
1.106.6 raises `litellm.InternalServerError` ("Connection error.") for a refused connection, not
`APIConnectionError`, so `model.chat` never raised `ModelServerDown`. Round 2 adds two files to scope:
`src/agent_lab/model.py` and `tests/test_model.py`. Keep everything else built in round 1.
- `model.py`: right after `import litellm`, set `litellm.suppress_debug_info = True` (no "Give Feedback" banner).
- In `chat()`, after the `litellm.Timeout` branch, catch `litellm.APIConnectionError` and
  `litellm.InternalServerError` together:
  - `APIConnectionError` always gives `ModelServerDown` (same message as today);
  - `InternalServerError` gives `ModelServerDown` (same message) when `model_server.port_in_use(settings)` is
    false. Otherwise it gives `ModelError(str(error))`.

  Chain with `from`. The `BadRequestError` branch stays.
- `tests/test_model.py` adds, keeping every existing test:
  - `litellm.InternalServerError("Connection error.", llm_provider="openai", model="m")` with `port_in_use`
    patched false gives `ModelServerDown` with the exact message;
  - the same error with `port_in_use` patched true gives `ModelError` containing `Connection error.`;
  - `litellm.suppress_debug_info is True` after import.

## Acceptance criteria
1. **Lesson file** `lessons/01_model_call.py`, runnable alone.
   - It starts with a module docstring of 2 to 4 short sentences that says what the learner will see (checked in
     review).
   - `main` has a docstring too. Every docstring sentence has at most 20 words (the AC3 test).
   - `main(argv=None) -> int` uses argparse with `--fake` (`nargs="?"`, `const=` the built-in script
     `fakes.builtin("01_model_call")`, default `None`). A given path is a custom script.
   - Steps. Each step has a plain-English comment before its code that says what happens and why (REQ-052, eli5,
     ASD-STE100; checked in review):
     1. build two messages: system `You are a patient teacher. Answer in one short sentence.` and user
        `What is a large language model?`;
     2. print each message as `system> <text>` and `you> <text>`;
     3. pick the model: `fakes.FakeModel(script).chat` with `--fake`, else `model.chat`;
     4. call `chat(messages)` once, with no tools and no `thinking` argument (so thinking stays off, D-013);
     5. print `agent> <reply text>`;
     6. print `[tokens] prompt=<n> completion=<n> total=<n>` from `reply.usage`, a dict with the keys
        `prompt_tokens`, `completion_tokens` and `total_tokens`.
   - Errors print `error: <message>` to stderr and return 1, with no traceback:
     - `model.ModelError` and its subclasses, `model_server.ModelServerError`, `settings.SettingsError`;
     - `ValueError` (a bad or missing fake script);
     - `fakes.ScriptExhausted`, printed as `error: the fake script has no more replies`.

     Return 0 on success. Lessons use exit 1 for every error; REQ-040's exit 2 is a rule for the CLI `chat`
     only.
   - `if __name__ == "__main__": raise SystemExit(main())`.
   - Imports come from the installed package (`from agent_lab import fakes, model, model_server, settings`); no
     `sys.path` edits.
2. **Fake script** `src/agent_lab/fake_scripts/01_model_call.json`: one reply,
   `{"text": "A large language model is a program that predicts the next words of a text."}`.
3. **Docstring test** `tests/test_docstrings.py` (REQ-052 AC1). It walks every `*.py` under `src/agent_lab/` and
   `lessons/` (a missing folder is skipped), skipping `__pycache__`. It reads each file with `encoding="utf-8"` and
   uses `ast`:
   - every module has a docstring;
   - every public class and public function or method (name not starting with `_`) has a docstring;
   - every docstring found (module, class, function, method, private ones included) has no sentence over 20
     words. The text is `ast.get_docstring(node)`. Sentences come from `re.split(r"[.!?](?:\s+|$)", doc)`, and
     words from `split()`.

   A failure message reads `<relative path>:<line> <object name>: <problem>`.
4. **Lesson test** `tests/test_lesson_01.py`:
   - run `[sys.executable, "lessons/01_model_call.py", "--fake"]` with `cwd=ROOT`,
     `env={**os.environ, "PYTHONPATH": str(ROOT / "src")}`, `capture_output=True`, `text=True` and `timeout=60`;
   - expect exit 0, stdout containing `system> You are a patient teacher.`, `you> What is a large language model?`,
     `agent> A large language model is a program that predicts the next words of a text.` and
     `[tokens] prompt=0 completion=0 total=0`;
   - a custom script in `tmp_path` (`[{"text": "custom reply"}]`) passed after `--fake` prints
     `agent> custom reply`;
   - an empty script (`[]`) exits 1. Stderr contains `error: the fake script has no more replies` and no
     `Traceback`;
   - `--fake` with a path that does not exist exits 1. Stderr contains `error:` and no `Traceback`;
   - the lesson file text (read as UTF-8) contains no `http://` or `https://`.
5. **Local only.** The lesson contains no URL (tested in AC4). The repo-wide REQ-053 scan comes in a later
   feature. The live path (`settings.load` and `model.chat`) is checked by hand, not in pytest.
6. **Full suite.** `.venv\Scripts\python.exe -m pytest -rs` passes, with 0 skipped. The existing
   `test_project.py` path scan now also covers `lessons/`; the new files must not contain drive letters or
   `\Users\` paths.
