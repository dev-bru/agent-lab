## Acceptance criteria
1. `model.py`: add `def server_down(settings) -> ModelServerDown` (with a docstring) that returns
   `ModelServerDown(f"cannot reach the model at {settings.host}:{settings.port}; run: agent-lab model start")`.
   `model_error` uses it instead of its own copy of that text. The text does not change.
2. `cli.py`, chat: when `args.fake is None`, right after `model_server.check_host(config)`, add
   `if not model_server.port_in_use(config): raise model_module.server_down(config)` with a short comment: fail
   before the slow tool start and LiteLLM import. This runs before the engine is chosen and before
   `McpTools` opens, for both engines. The existing `except model_module.ModelServerDown` prints the error and
   returns 2, as now.
3. `tests/test_cli.py`: keep `test_stopped_model_server` unchanged. Add one in-process test (with a docstring):
   call `cli.main(["chat"])` with `AGENT_LAB_HOST=127.0.0.1` and a free port (as in `test_stopped_model_server`),
   with `mcp_client.McpTools` replaced by a stub that fails the test if it is created (`monkeypatch`); assert the
   return code is 2 and stderr (`capsys`) contains `cannot reach the model at 127.0.0.1:` and
   `agent-lab model start`. Do not add timing assertions.
4. Run only the test command below. The orchestrator runs the full offline suite: 0 skipped, at least 190 passed
   (MEASURED after AL-T-003) plus the new test.
