## Acceptance criteria
1. **Lesson** `lessons/04_agent_loop.py`, runnable alone.
   - It has a module docstring of 2 to 4 short sentences (review). Every function has a docstring with at most 20
     words per sentence (`tests/test_docstrings.py`). There is a plain comment before each step.
   - It imports `agent_lab` (`fakes`, `model`, `model_server`, `settings`, `mcp_client`, `trace`, and
     `agent.hand`) and the standard library.
   - `QUESTION = "What is 17 times 23? Save the answer as a note called result."`.
   - `run(chat_model) -> int`, where `chat_model` has `.chat(messages, tools=...)` (`model` module or a
     `FakeModel`). Steps:
     1. `config = settings.load()`; print `you> <QUESTION>`;
     2. `with mcp_client.McpTools(settings=config) as tools, trace.Trace.new(config.runs_dir, "hand") as log:`;
     3. `result = hand.run(QUESTION, model=chat_model, tools=tools, trace=log, echo=print)`;
     4. print `agent> <result.text>`, then `[trace] <log.path>`;
     5. return 0 when `result.stopped_by == "answer"`, else 1 (the limit message is already the printed text).
   - `main(argv=None) -> int` parses `--fake [SCRIPT]` with `const=fakes.builtin("two_tool")` and calls `run` with
     `fakes.FakeModel(script)` or the `model` module. Like lesson 02, it catches `ValueError` from building the
     `FakeModel`, prints `error: <message>` to stderr and returns 1.
   - Errors print to stderr and return 1, with no traceback. One `try` wraps the whole body of `run` (settings load,
     the `with` block and `hand.run`). `except fakes.ScriptExhausted` comes first and prints
     `error: the fake script has no more replies`. Then `except (model.ModelError, model_server.ModelServerError,
     settings.SettingsError, mcp_client.McpError, OSError, ValueError)` prints `error: <message>` (`OSError`
     because `Trace.new` can fail on a runs folder that cannot be written).
2. **Tests** `tests/test_lesson_04.py` (subprocess as in `test_lesson_02.py`, with `cwd=ROOT`, `PYTHONPATH=src`,
   utf-8, `timeout=120`, and env `AGENT_LAB_NOTES_DIR=<tmp_path>/notes` and `AGENT_LAB_RUNS_DIR=<tmp_path>/runs`
   so nothing is written in the repo). Cover:
   - REQ-013 AC1: `--fake` exits 0; stdout contains `[step 1/6]`, `[tool: multiply] 391`,
     `[tool: write_note] saved note 'result'`, a line starting `agent> ` that contains `391`, and a `[trace] ` line;
     `<tmp_path>/notes/result.md` exists; exactly one `*-hand.jsonl` file is in `<tmp_path>/runs`, and its last
     line has `"kind": "final"`;
     `[tool: multiply] 391` is a substring check: the real server prints `391.0`. Do not assert an exact line, and
     do not change the server or `hand.run`;
   - a script written to `tmp_path`, `[{"tool_calls": [{"name": "multiply", "arguments": "{\"a\": 2, \"b\": 3}"}]}]
     * 6`, passed as `--fake` plus that file's path, exits 1, and stdout contains
     `Stopped: reached the step limit (6 model calls).`;
   - an empty script `[]` in `tmp_path` exits 1; stderr contains `error: the fake script has no more replies` and
     no `Traceback`;
   - the lesson source has no `http://` or `https://`.
3. **Full suite.** `.venv\Scripts\python.exe -m pytest -rs -W error::DeprecationWarning` passes, with 0 skipped and
   at least 133 (MEASURED after F-011) plus the new test functions. `test_docstrings.py` and other tests are not
   edited.
