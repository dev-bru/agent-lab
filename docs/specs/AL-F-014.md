## Acceptance criteria
1. **Lesson** `lessons/06_langgraph_agent.py`, runnable alone, built like `lessons/04_agent_loop.py`.
   - It has a module docstring of 2 to 4 short sentences that says it is lesson 04's task with LangGraph (review).
     Every function has a docstring with at most 20 words per sentence (`tests/test_docstrings.py`). There is a plain
     comment before each step.
   - It imports `agent_lab` (`fakes`, `model`, `model_server`, `settings`, `mcp_client`, `trace`, and
     `agent.graph`) and the standard library. Importing `model` is used by the `except` tuple.
   - `QUESTION = "What is 17 times 23? Save the answer as a note called result."`.
   - `run(chat_model) -> int`, where `chat_model` is a LangChain chat model (`graph.chat_model(config)` or a
     `fakes.FakeChatModel`). Steps:
     1. `config = settings.load()`; print `you> <QUESTION>`;
     2. `with mcp_client.McpTools(settings=config) as tools, trace.Trace.new(config.runs_dir, "graph") as log:`;
     3. `result = graph.run(QUESTION, model=chat_model, tools=tools, trace=log, echo=print)`;
     4. print `agent> ` followed by `result.text`, then `[trace] ` followed by `log.path`;
     5. return 0 when `result.stopped_by == "answer"`, else 1.
   - `main(argv=None) -> int` parses `--fake [SCRIPT]` with `const=fakes.builtin("two_tool")`. It builds the chat
     model inside one `try`: `fakes.FakeChatModel(args.fake)` with `--fake`, otherwise `graph.chat_model()` (which
     loads settings itself). It catches `(ValueError, OSError, ImportError)` (`SettingsError` and pydantic's
     `ValidationError` are `ValueError`), prints `error: ` plus the message to stderr and returns 1.
   - Errors print to stderr and return 1, with no traceback. One `try` wraps the whole body of `run`, including
     `settings.load()` and the `with` block, as in lesson 04.
     `except fakes.ScriptExhausted` comes first and prints `error: the fake script has no more replies`. Then
     `except (model.ModelError, model_server.ModelServerError, settings.SettingsError, mcp_client.McpError,
     OSError, ValueError)` prints `error: ` plus the message.
2. **Tests** `tests/test_lesson_06.py`, built like `tests/test_lesson_04.py` (subprocess with `cwd=ROOT`,
   `PYTHONPATH=src`, utf-8, `timeout=120`, env `AGENT_LAB_NOTES_DIR` and `AGENT_LAB_RUNS_DIR` set to folders in
   `tmp_path`, so nothing is written in the repo). The subprocess helper always puts `--fake` first, then the
   optional script path, as lesson 04's test does. `-W error::DeprecationWarning` applies to the pytest process
   only; do not add it to the subprocess. Every test function has a docstring. Cover:
   - REQ-015 AC1: `--fake` exits 0. The stdout lines that start with `[node: `, in order, equal exactly
     `[node: model]`, `[node: tools]`, `[node: model]`, `[node: tools]`, `[node: model]`. Stdout also contains
     `[tool: multiply] 391` (substring: the real server prints `391.0`), `[tool: write_note] saved note 'result'`,
     a line starting `agent> ` that contains `391`, and a `[trace] ` line. `<tmp_path>/notes/result.md` exists.
     Exactly one `*-graph.jsonl` file is in `<tmp_path>/runs`, and its last line has `"kind": "final"`;
   - a script written to `tmp_path`, `[{"tool_calls": [{"name": "multiply", "arguments": "{\"a\": 2, \"b\": 3}"}]}]
     * 6`, passed as `--fake` plus that file's path, exits 1, and stdout contains
     `Stopped: reached the step limit (6 model calls).`;
   - an empty script `[]` in `tmp_path` exits 1; stderr contains `error: the fake script has no more replies` and
     no `Traceback`; the one `*-graph.jsonl` file's last line has `"kind": "error"`;
   - the lesson source has no `http://` or `https://`.
3. **Full suite.** `.venv\Scripts\python.exe -m pytest -rs -W error::DeprecationWarning` passes, with 0 skipped and
   at least 147 (MEASURED after F-013) plus the new test functions. No other test is edited.
