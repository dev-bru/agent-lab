## Goal
`agent-lab model start|stop|status` controls the local llama-server, so later lessons can call the model. Every
step is safe on native Windows, local only, and explained in plain English.

## Acceptance criteria
1. **Command line.** `command(settings) -> list[str]` returns exactly `[settings.llama_server, "-m",
   settings.model, "--jinja", "-ngl", "99", "-c", "8192", "--host", settings.host, "--port", str(settings.port)]`.
2. **Checks.** `class ModelServerError(RuntimeError)` is defined in `model_server.py`.
   - `check_host(settings)` raises `host must be 127.0.0.1 or localhost, got '<host>'` for any other host.
     `healthy`, `port_in_use`, `start` and `status` call it first, so no function connects to another host.
   - `check(settings)` runs `check_host`, then the files:
     - `llama_server` is accepted when `Path(value).is_file()` or `shutil.which(value)` finds it, else
       `llama_server not found: <value>`;
     - `model` must be a file, else `model not found: <value>`.
3. **State folder.** Every public function takes `home: Path` (the CLI passes `Path(".agent-lab")`). The pid file
   `home / "model.pid"` holds the pid as ASCII digits and a newline. The log is `home / "model.log"`. `start`
   creates `home`. A pid file that is empty, not an integer, or not a positive integer is stale: delete it and treat
   the server as stopped.
4. **Process helpers** (standard library only; `subprocess.DETACHED_PROCESS` and `CREATE_NEW_PROCESS_GROUP` exist on
   Windows only, which is intended):
   - `pid_alive(pid: int) -> bool`:
     - `pid <= 0` gives false;
     - use `kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)`, with `restype`/`argtypes` set from
       `ctypes.wintypes` (`OpenProcess.restype = wintypes.HANDLE`);
     - `OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION (0x1000), False, pid)`. A null handle gives true only when the
       last error is 5 (access denied), else false;
     - `GetExitCodeProcess` equals `STILL_ACTIVE` (259); `CloseHandle` in a `finally`;
     - it must NOT use `os.kill` (on Windows that terminates the process).
   - `healthy(settings) -> bool`: GET `/health` with a 2 s timeout via `urllib.request`. Build the URL with
     `urllib.parse.urlunsplit(("http", f"{host}:{port}", "/health", "", ""))`, so the source has no `http://`
     literal (REQ-053 scan). True only for status 200; any error gives false.
   - `port_in_use(settings) -> bool`: `socket.create_connection((host, port), timeout=1)` succeeds.
   - `_kill(pid) -> subprocess.CompletedProcess`: `subprocess.run(["taskkill", "/PID", str(pid), "/T", "/F"],
     capture_output=True, text=True)`, no shell.
5. **start(settings, home) -> int:**
   1. run `check` (raises on failure);
   2. if the pid file holds a live pid and `healthy` is true: print `already running`, return 0. A live pid that is
      not healthy counts as not running; the pid file is left as it is;
   3. if `port_in_use`: print `port <port> is in use by another process`, return 1;
   4. open the log in append mode (`"ab"`), `subprocess.Popen(command(settings), stdout=log, stderr=STDOUT,
      stdin=DEVNULL, creationflags=DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP)`, close the log in the parent,
      write the pid file;
   5. wait up to `min(settings.timeout_s, 120)` seconds, using `time.monotonic` and `time.sleep(1)`. Each round:
      if `proc.poll() is not None` the start failed; else if `healthy`, print `running (pid <pid>)` and return 0;
   6. on failure or timeout: call `_kill(pid)` when the process is still alive, delete the pid file, print
      `model server did not start; see <log path>`, return 1. Do not print `stopped`.

   Each step has a one-line comment that says why.
6. **status(settings, home) -> int:** run `check_host`. With no pid file, a stale pid file (AC3) or a dead pid,
   print `stopped` WITHOUT calling `healthy`, and delete a pid file whose process is gone. With a live pid, print
   `running` when `healthy`, else `stopped`. Return 0.
7. **stop(settings, home) -> int:** no pid file, stale file or dead pid: delete any pid file, print
   `already stopped`, return 0. Otherwise call `_kill(pid)`:
   - return code 0: delete the pid file, print `stopped`, return 0;
   - non-zero: print `could not stop pid <pid>:` and the taskkill output, keep the pid file, return 1.
8. **CLI.** `model` takes a required positional `action` with `choices=["start", "stop", "status"]` (a missing
   action is an argparse error, exit 2). It loads settings with `settings.load()`, calls the function with
   `home=Path(".agent-lab")`, and returns its code. On `SettingsError` or `ModelServerError` it prints the message
   to stderr and returns 1. `chat` keeps its placeholder.
9. **Plain English (REQ-052).** Every module and every function (public and private) has a docstring in short
   eli5, ASD-STE100 sentences, at most 20 words each.
10. **Tests** (`tests/test_model_server.py`, pytest, `tmp_path`, `monkeypatch`). No test may start
    `llama-server`, run `taskkill` or contact a real port, except the live test. An autouse fixture patches
    `subprocess.Popen`, `agent_lab.model_server._kill` and `healthy` to fail the test when called; each test that
    needs one overrides it. Tests that call `start` also patch `port_in_use` (unless testing it), `time.sleep` and
    `time.monotonic`. The file must not contain drive-letter or `\Users\` paths (the `test_project.py` scan).
    Cover:
    - AC1: the command list for settings loaded from `agent-lab.example.toml`;
    - AC2:
      - a non-local host raises naming the host, for `check`, `status` and `healthy`;
      - missing `llama_server` and missing `model` raise naming the setting and the value;
      - a bare `llama_server` name accepted through a patched `shutil.which`;
    - already running: pid file present, `pid_alive` and `healthy` patched true: prints `already running`, 0;
    - port in use: bind a socket on `127.0.0.1` port 0 and set the settings port to it, with real files in
      `tmp_path`. It returns 1 and the message has the port. `Popen` is not called;
    - stale pid: run `[sys.executable, "-c", "pass"]` to completion, then write its pid. `status` prints `stopped`
      and the file is gone. `stop` prints `already stopped` and returns 0. `_kill` is not called;
    - a corrupt pid file (`abc`) is treated as stopped and deleted;
    - `pid_alive(os.getpid())` is true, and `pid_alive(0)` is false;
    - start success: a fake process (pid 4242, `poll()` None) and `healthy` true. It prints `running (pid 4242)`,
      the pid file holds `4242`, and `Popen` got the command list and both creation flags;
    - start failure: `poll()` returns 1. It returns 1, the pid file is gone, the message names the log, and
      `stopped` is not printed;
    - start timeout: `healthy` is always false, `poll()` None, and the patched clock passes 120 s. `_kill` is called
      once, the pid file is gone, and it returns 1;
    - stop:
      - `pid_alive` true, `_kill` returns code 0: the pid file is gone, it prints `stopped`, 0;
      - `_kill` called directly with `subprocess.run` patched gets the exact taskkill list;
      - a non-zero `_kill` returns 1 and keeps the pid file;
    - CLI (`monkeypatch.chdir(tmp_path)`):
      - `main(["model", "status"])` prints `stopped` and returns 0, and `healthy` is not called;
      - `AGENT_LAB_PORT=abc` returns 1;
      - `AGENT_LAB_HOST=example.com` with `start` returns 1;
      - a missing model with `start` returns 1 and names the model;
    - REQ-052 and REQ-053 for this task's files:
      - an `ast` check that every function in `model_server.py` and `cli.py` has a docstring and no docstring
        sentence has more than 20 words;
      - `model_server.py` contains no `http://` or `https://` text;
    - live (`@pytest.mark.live`, run by the orchestrator with `-m live`, which overrides `addopts`):
      - settings come from `settings.load(ROOT / "agent-lab.toml")` with `ROOT = Path(__file__).resolve().parents[1]`;
      - skip when that file is missing or the port is already in use;
      - `home` is `tmp_path`;
      - steps: start, status `running`, stop, status `stopped`.
