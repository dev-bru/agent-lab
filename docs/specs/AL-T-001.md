# Task spec: AL-T-001 Faster offline tests: load LiteLLM only for real model calls

Traces to: REQ-050 (fast offline tests) in `docs/REQUIREMENTS.md`; no feature in `feature_list.json` (a technical
task). MEASURED 2026-10-31 on this PC: the full suite takes 326 s; about 25 lesson tests start a Python
subprocess and take 9 to 19 s each. `import litellm` alone takes 8.1 s; `agent_lab.fakes` takes 8.9 s because it
imports `agent_lab.model`, which imports `litellm` at the top. A `--fake` run never calls LiteLLM.
Mode: write   Budget: 30 min   Risk: low
Blast radius: two module imports and one test. No behaviour change for real model calls.

## Goal
A `--fake` lesson run, and any import of `agent_lab.fakes`, `agent_lab.model` or `agent_lab.agent.graph`, does not
load LiteLLM. LiteLLM loads only when a real model call or a real chat model is made.

## Files in scope (only these may change)
- src/agent_lab/model.py
- src/agent_lab/agent/graph.py
- tests/test_model.py
- tests/test_import_cost.py (new)

## Out of scope
- Every other source file, lesson and test; `pyproject.toml`; `docs/**`; `feature_list.json`.
- New dependencies (no pytest-xdist).

## Acceptance criteria
1. **`model.py`.** The environment setup at the top of the module stays as it is (`LITELLM_LOCAL_MODEL_COST_MAP`,
   `NO_PROXY`, `no_proxy`), so it still runs at import. The top-level `import litellm` and
   `litellm.suppress_debug_info = True` move into `chat()`: `import litellm` as the first statement of `chat()`,
   then `litellm.suppress_debug_info = True`, with a one-line teaching comment saying LiteLLM loads here because it
   is slow to import and fake runs do not need it. Everything else in `chat()` stays the same and still refers to
   `litellm.<name>`.
2. **`agent/graph.py`.** The top-level `from langchain_litellm import ChatLiteLLM` moves into `chat_model()`. The
   return annotation becomes the string `"ChatLiteLLM"`, with `from typing import TYPE_CHECKING` and
   `if TYPE_CHECKING: from langchain_litellm import ChatLiteLLM` at the top. Nothing else changes.
3. **`tests/test_model.py`.** `test_litellm_banner_is_suppressed` keeps its assertion
   `litellm.suppress_debug_info is True`, but first sets `litellm.suppress_debug_info = False` and makes one
   `model.chat(...)` call with `litellm.completion` patched by `monkeypatch` (as the other tests in the file do).
   No other test in the file changes, and no assertion is removed or weakened.
4. **`tests/test_import_cost.py`** (new; every test has a docstring). Each test runs a subprocess
   (`sys.executable`, `cwd=ROOT`, env with `PYTHONPATH=src`, utf-8, `timeout=60`) whose code prints
   `"litellm" in sys.modules` and `"langchain_litellm" in sys.modules` after the action, and asserts both are
   `False`:
   - `import agent_lab.fakes, agent_lab.model, agent_lab.agent.graph`;
   - running `lessons/01_model_call.py` with `--fake` in-process in that subprocess: load it with
     `importlib.util.spec_from_file_location`, call `main(["--fake"])`, and require it to return 0.
5. **Full suite.** `.venv\Scripts\python.exe -m pytest -rs -W error::DeprecationWarning` passes, with 0 skipped and
   at least 151 (MEASURED after F-014) plus the new test functions.
