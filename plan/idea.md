Learning project on agentic AI fundamentals, running fully on this PC. My own MCP server built with FastMCP, with a tool catalog: math and units (safe calculator, unit converter), notes in a sandbox folder (add, list, read, search), date and time (now, difference, time zones), and local docs search (with MCP resources). A small local model, Qwen3 1.7B, served by llama.cpp's llama-server from a local folder (OpenAI-compatible API, tool calling verified); no need for it to be smart. A simple agent built two ways: first by hand in plain Python on LiteLLM (model call, tool call, structured output, agent loop) so every moving part is visible, then the same agent in LangGraph to see what the framework does for you. Teaches model APIs, tool calling, structured outputs, agent loops and MCP. CLI chat plus a per-run trace file replayed by an HTML trace viewer. Plain-English comments everywhere (eli5 + ASD-STE100), and interactive architecture and flow diagrams (architecture-diagram skill) showing how the agent and each fundamental work. Also a real end-to-end test of the harness and dashboard v3: screenshot every page while it is built.
